# ZigMV

> One native protocol for fast telemetry, work distribution, acknowledged delivery, and retained device state.

ZigMV is a lightweight messaging protocol for **cloud services, IoT devices, and edge gateways**. It combines NATS-inspired subject routing and service patterns with MQTT-inspired device-oriented delivery and retained state in a single canonical message envelope.

ZigMV is a new protocol. It is not MQTT with an extension and not NATS joined to MQTT by an internal bridge. Existing MQTT and NATS systems can migrate through boundary adapters, while new applications can use the native `ZMV/1` protocol directly.

## Choose the right profile

Use `live` for replaceable telemetry, `work` for one-of-N jobs, `durable` for acknowledged connected-session delivery, and `state` for last-value device state. Do not use `live` for commands that cannot be lost.

<Note>
The current 100M messages/sec run is an offered-rate stress target, not a verified end-to-end capacity claim. Always report accepted, delivered, lost, duplicate, gap, and latency metrics together.
</Note>
